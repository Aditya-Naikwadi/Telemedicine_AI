# Telemed AI Agent Examples

This directory contains examples demonstrating how to use the Telemed AI Agent package.

## Examples

### basic-usage.ts

Demonstrates basic agent initialization and chat functionality.

```bash
# Run the example
npx ts-node examples/basic-usage.ts
```

## Prerequisites

Before running the examples, make sure you have:

1. Installed dependencies:
```bash
npm install
```

2. Set your OpenAI API key:
```bash
export OPENAI_API_KEY=your-api-key-here
```

## What the Examples Show

- **Agent Initialization**: How to create and configure the agent
- **Chat Functionality**: Sending messages and receiving responses
- **Emergency Detection**: Automatic detection of critical symptoms
- **Session Management**: Maintaining conversation context
- **Welcome Messages**: Getting started with new patients
